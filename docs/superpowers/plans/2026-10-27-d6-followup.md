### Task 1: 菜单翻转钳制 + SubMenu 子菜单

**Files:**

- Test: `tests/SharpUI.Tests/MenuTests.cs`

**Interfaces(Produces):**

```csharp
namespace SharpUI;

public sealed class MenuSub(string label, params object?[] children)   // 与 MenuItem/MenuSeparator 同混排
{
    public string Label { get; } = label;
    public object?[] Children { get; } = children;
    public bool Enabled { get; init; } = true;
}

// MenuExtensions.Show 增可选 screenSize(默认查窗口逻辑尺寸,无窗则无穷大不钳制,兼容既有测试):
//   底部溢出(anchor.Bottom + menuH > screenH)→ y = anchor.Y - menuH(再 <0 则钳 0);
//   右侧溢出(anchor.X + menuW > screenW)→ x = screenW - menuW(再 <0 则钳 0);
//   SubMenu 锚=父项右缘(x = parentItem.Right, y = parentItem.Y),左侧翻转:溢出则 x = parentItem.X - subW。
//   2 层上限:子菜单内再含 MenuSub → 抛 InvalidOperationException("SubMenu 最多 2 层(主菜单+一级子菜单)")。
//   悬停父项 ≥0.2s(复用 TooltipService 墙钟模式或菜单自持计时)或聚焦按 Right/Enter → 展开子菜单
//     (先按身份 Remove 兄弟旧子菜单);子菜单内按 Left/Esc 仅关子菜单、焦点归还父项;
//   子菜单项激活 → 回调 + **连带关闭父菜单**(整棵菜单树收起)。父项尾绘 ▶ 箭头(AddStroke 同款)。
```

- [ ] **Step 1: 写失败测试**(MenuTests.cs 追加):
  - 翻转钳制:传入 screenSize=(200,100),anchor 在底缘 (10,80,40,15) → 菜单 y 向上翻(<80);右侧溢出 → x 钳制;无 screenSize(既有测试)行为不变。
  - SubMenu:Right/Enter 展开(Count==2,焦点入子首项);Left/Esc 仅关子菜单(Count==1,焦点归还父项);子项激活 → 回调+整棵收起(Count==0);悬停 0.2s 展开+切兄弟父项替换旧子菜单;3 层抛 InvalidOperationException;禁用 MenuSub 跳过。

### Task 2: 定位收敛 + 滚轮栅门 + Slider Range 键盘切换

**Files:**
- Modify: `src/SharpUI/Focus.cs`/`Element.cs`/`MenuElement.cs`(三套定位窗收敛)、`src/SharpUI/App.cs`/`Scroll.cs`(浮层滚轮栅门)、`src/SharpUI/Elements/SliderElement.cs`(Range `Space` 切换活动 thumb + 视觉区分)
- Test: `tests/SharpUI.Tests/PopupHostTests.cs`(滚轮栅门)、`tests/SharpUI.Tests/SliderTests.cs`(Range Space 切换)

**Interfaces:**
- **定位收敛**:`FocusManager.SdlWindow` 唯一真相;Element.OwnerFocus 保留(声明式入口,OwnerFocus.SdlWindow 即句柄);`FocusManager._byWindow` 仅留作命令式 `Ui.ShowMenu(IntPtr)` 入口桥,注释写明分工(删除任何冗余句柄字段,若有)。
- **滚轮栅门**:`App.Run` 的 `Scroll.Dispatch` 调用:若该窗 `PopupHost.TopOf(sdlWindow)` 非空且 Kind≠Tooltip → 仅对**栈顶浮层根** Dispatch(浮层内有 Scroll 则滚浮层,无则吞掉不穿透声明树);Tooltip 在顶则穿透(Tooltip 不挡下层滚动,与 T1 评审观察一致)。
- **Slider Range `Space` 切换**:Range 模式下 `HandleKey(Key.Space)` → 翻转 StateStore 中活动 thumb 锁存 0↔1,消费返回 true(单 thumb 模式 Space 不消费);Draw 侧活动 thumb 描 1px 亮边(0x93C5FD)区分。

- [ ] **Step 1: 写失败测试**:
  - 滚轮栅门:声明树含 Scroll(初始 offset 0)+ Dialog 打开(无 Scroll)→ 合成 Wheel → 声明树 Scroll offset 仍为 0(被吞);Dialog 内含 Scroll → 合成 Wheel → Dialog 内 Scroll offset 变化、声明树不变;仅 Tooltip 在顶 → 声明树 Scroll 正常滚动。
  - Slider Range Space:聚焦 Range(20,80) → Right 动 min(默认 0)→ Space → Right 动 max(切到 1)→ 再 Space → Home 动 min。
