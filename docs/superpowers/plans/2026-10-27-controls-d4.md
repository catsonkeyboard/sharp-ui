# D4 控件库扩展 + 性能债批次 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 Checkbox/Radio/Slider(全功能)三控件 + 拖拽捕获原语,完成性能债批次(D3D11 部分上传/GL drawable/多窗多线程评估)与 IME 候选序前置修复,金样本/基线全绿。

**Architecture:** 三控件按 ButtonElement 模式(PanelElement 子类+Draw 重写+StateStore 键盘);拖拽捕获原语落 Interaction(静态会话态);D3D11 缓冲改 DYNAMIC+Map/Unmap,GLContext 接 drawable 尺寸;IME 候选序与 LiveModule 同构。

**Tech Stack:** .NET 10、SDL2 2.30.8(仅 drawable 查询)、xUnit 合成事件(InjectTest 模式)。

**Spec:** `docs/superpowers/specs/2026-10-27-controls-d4-design.md`(C-1~C-5 已批准)

## Global Constraints

- 零 `unsafe`;NativeAOT 兼容;绘制缓存命中路径零新分配意图(控件 Draw 不得 ToArray/new)。
- 回调式状态(C-2):控件不藏状态;`Action` 回调仅在值实际变化时触发。
- 色板沿用 Button 硬编码(0x0C63E4/0x3B82F6/0x1D4ED8 + 禁用灰 0x3A3A42);主题化范围外。
- 金样本 6/6 与双后端 harness 是渲染路径改动的护栏(D3D11 上传任务必须复跑)。
- IME 回归复验是 C-5 硬门槛(桌面解锁,流程同窗口层 T4)。
- 全量测试门槛:基线 299/299(新增另计);性能基线 ≤5490B/0.05ms 不破(预期下降)。
- AOT 产物记录(预期 ~6MB 级);git 每任务至少一提交。

```csharp
// Interaction.cs 增(静态会话态,同 HoveredId 模式):
public static string? CapturedId { get; internal set; }   // 捕获中的元素;null=无
// Update 语义:LeftDown 命中 IsHitTarget 且该元素声明可捕获(见下)→ CapturedId=其 ResolvedId;
// 捕获期间:MouseMotion/LeftUp 仍路由到捕获元素(HitTest 路径旁路),HoveredId 锁定捕获者;
// LeftUp 释放 CapturedId=null;新 LeftDown 覆盖旧捕获。
// "声明可捕获":Element 增 internal virtual bool CapturesDrag => false;(Slider 覆写 true;Checkbox/Radio 不捕获——
//   它们是点击切换语义,按下在元素内松开才触发,现有点击语义即可)
// 注:捕获只影响 MouseMotion/Up 的"命中"判定,Click(Down+Up 同元素)语义不变。

// CheckboxElement:
public sealed class CheckboxElement : PanelElement
{
    public CheckboxElement(string label, bool isChecked, Action<bool>? onChanged);
    public bool Enabled { get; set; }            // false=禁用视觉(灰)+不响应
    // Draw:方框 14×14(左)+label TextElement(Add 子元素,垂直居中);勾=两段 quad(白);
    // 键盘:聚焦+Space/Enter → 切换(经 HandleKeys 消费路径,同 TextField 模式——若 Focus.HandleKeys 不分发给
    //   PanelElement 子类,则实现 ITextFeedable 式接口或扩展现有键盘路由,实现者按现状选最自然路径并报告)
}
// RadioElement:
public sealed class RadioElement : PanelElement
{
    public RadioElement(string label, string groupName, bool isSelected, Action? onSelected);
    public bool Enabled { get; set; }
    // 圆圈 14×14 + 内点(选中);键盘:方向键组内循环(FocusManager 需暴露同 groupName 焦点邻居查询——
    //   实现者按 Focus 现状选最自然路径:或在 RadioElement 内静态按 groupName 注册表,或在 FocusManager 加分组;报告写明)
}
// Ui.cs:
public static CheckboxElement Checkbox(string label, bool isChecked, Action<bool>? onChanged) => new(label, isChecked, onChanged);
public static RadioElement Radio(string label, string groupName, bool isSelected, Action? onSelected) => new(label, groupName, isSelected, onSelected);
```

**Interfaces(Produces):**

```csharp
public sealed class SliderElement : PanelElement
{
    public SliderElement(float min, float max, float value, Action<float> onChanged);
    public SliderElement Step(float step);              // 0=连续(默认);>0 吸附
    public SliderElement Vertical();                     // 方向(默认横向)
    public SliderElement Range(float maxValue, Action<float>? onMaxChanged);  // 双 thumb 区间
    public bool Enabled { get; set; }
    // 内部:thumb 8×16(横)/16×8(纵);轨道 4px 居中;
    // CapturesDrag=true;拖拽:Down 于 thumb→捕获,Motion→值=f(位置钳制+Step 吸附),Up→释放;
    // 轨道点击:Down 于轨道(非 thumb)→ thumb 就位并捕获续拖;
    // Range:双 thumb 各自捕获;交叉时钳制(minValue ≤ maxValue−step 或最小间距);
    // 键盘:左右(纵向上下)±step 或 ±(max−min)/20(连续);Home=min/End=max(单 thumb 左/Home,右/End);
    //   Range 模式 Home/End 操作当前捕获/最后操作的 thumb;
    // 回调:仅值实际变化(钳制+吸附后)触发;双 thumb 各自回调。
}
// Ui.cs: public static SliderElement Slider(float min, float max, float value, Action<float> onChanged) => new(...);
```
